## 1. 意图

做一个能让招聘方（HR、面试官）和同行**一打开就停下来**的个人作品集网站。

整个网站是一台复古的**胶片阅读机**：左右两个卷片盘，中间一条胶片，胶片的每一帧是一个栏目。访客卷动胶片挑选栏目，拧旋钮"载入"，内容显示在机器的阅读屏幕上。

想要的感受：
- **第一眼**：氛围强，工业复古、暖光、黄铜、胶片颗粒，让人愿意多看几秒。
- **上手**：卷胶片、转旋钮的**手感**是整个网站最重要的时刻，要有重量、有惯性、有"咔嗒"一声停住的感觉。
- **读内容**：信息清楚好读，招聘方能很快找到项目、技能、证书和联系方式。

开场会直接问一句：**"Why should you hire Yaowei (Terry) Feng?"**，用来勾起 HR 的兴趣，答案就在后面的档案里。

## 2. 目标、非目标、反目标

**目标**
- 桌面端：一个可以交互的 3D 场景（three.js），核心是卷胶片和载入的手感。
- 手机和不支持 3D 的设备：一个同风格的 2D 版，内容完全一样。
- 中、英、日三种语言。
- 纯静态网站，部署在 GitHub Pages。
- 内容放在数据文件里，网站主人以后只改数据文件，不碰代码，就能更新内容。

**非目标**
- 不做后端、不做登录、不做评论、不做访问统计。
- 暂时不绑定自定义域名（但要能方便地加上）。
- 不追求照片级渲染；风格化但质感到位即可。
- 不做 Experience（经历）和 Resume（简历）栏目，以后也不打算加。网站就是四个栏目。

**反目标（功能都能用，但出现以下情况就算失败）**
- 看起来像一堆方块和圆柱拼起来的"积木"，显得廉价。
- 场景里的东西各说各话，看不出是**一台**机器（试验版早期出现过：放映机加上一个不明的透镜）。
- 访客进入阅读界面后不知道怎么出来、卡住了。
- 内容难读：字太小、太挤，或者被特效盖住。
- 打开太慢，又没有任何东西盖住等待时间。

## 3. 约束

- **技术栈**：three.js 做 3D。纯静态，最后产出的是 HTML/JS/CSS 加资源文件。
- **部署**：网站主人自己的 GitHub 仓库，用 GitHub Pages 发布。地址先按 `用户名.github.io` 这种主站形式来做；发布路径（base path）要做成一个可改的设置。
- **素材授权**：3D 模型只用 CC0（或同等宽松）授权的开源模型，目前全部来自 Poly Haven。其余部件用代码生成。
- **内容**：目前全部用占位内容，网站主人以后自己填。
- **浏览器**：桌面端以近两年的 Chrome、Edge、Safari、Firefox 为准。

## 4. 已经决定的设计

### 4.1 整体流程

```
开场过场 → 3D 阅读机（停在 About 帧）
              ├─ 卷胶片选栏目
              ├─ 载入 → 屏幕推近 → 阅读内容 → 返回
              └─ 切换语言 / 声音 / 简洁版（2D）
```

手机、平板竖屏、不支持 WebGL 的浏览器：开场过场（简化版）→ 直接进入 2D 版。

### 4.2 开场过场

- 大约 4 到 6 秒，用来盖住 3D 场景和模型的加载时间。
- 同样的暗色和暖光：黑暗里一盏灯慢慢亮起，像老放映机启动，有胶片颗粒和闪烁。打字机效果打出：**"Why should you hire Yaowei (Terry) Feng?"**，停一拍，下面出现一行小字（类似"答案在档案里"），然后镜头落到机器前，胶片停在 About 帧。
- 文字跟着当前语言显示。
- 一直有"跳过"按钮；看过一次的访客，下次自动缩短或跳过。
- 如果加载比过场慢，过场停在最后一个画面，加一个不打扰的加载提示，加载完再进入。
- 2D 版也有一个一两秒的简化开场（同一句话淡入淡出）。

### 4.3 3D 场景的组成

> 本节的机器结构已被 §8.1 取代。

整个场景是**一台**胶片阅读机，放在木质工作台上。结构参考真实的胶片剪辑台（左右卷片盘，胶片从中间经过）。试验版最终版的布局已经被网站主人认可，可以直接参考。

| 部件 | 说明 | 来源 |
|---|---|---|
| 左右卷片盘 | 装在铁支架上，盘面朝向镜头。胶片从左盘底部出来，经过中间，卷进右盘。右盘有木柄摇把。 | 片盘用 Poly Haven `filmstrip_projector_8mm` 模型里的片盘部件；支架、摇把用代码 |
| 胶片 | 横跨两个卷片盘，中段微微弯曲、向后倾斜躺着，到两端逐渐立起、卷进片盘。两端各有几帧片头（倒数数字、十字线）。 | 代码，每帧是一张程序画的复古棕褐色图片 |
| 读片口 | 胶片中间那一帧的位置：下方有底座，四周一圈黄铜框，停稳时边缘发出暖光。**上方没有镜头**，就是放映机那种"光从底下透上来读这一帧"的样子。 | 代码 |
| 阅读屏幕 | 机器中后方的屏幕，黄铜边框，后面是外壳。空闲时显示当前帧的标题和"按 Enter 或转动旋钮载入"。 | 边框用代码；外壳目前用 Poly Haven `television_02`（见 5. 留给开发者的） |
| 载入旋钮 | 右侧一个独立的控制件：铸铁底座、细立柱、表盘，表盘上刻着 VIEW 和 LOAD，上面是滚花黄铜大旋钮，带指针。**不要拉杆**，**旋钮后面不要再加盒子或面板**。 | 代码 |
| 台灯 | 右后方的摇臂台灯，灯光照向读片口。 | Poly Haven `desk_lamp_arm_01` |
| 环境 | 木质台面、暗色墙、远处一扇雾蒙蒙的工业窗、灯光里漂浮的灰尘、左前方一摞胶片铁盒。 | 代码 |

已经明确**不要**的东西：放映机机身、显微镜、仪器面板、读片口上方的镜头和吊臂、拉杆。

所有模型统一调色：降低原贴图的饱和度，往同一套暖铜色、旧金属色上靠，让模型和代码生成的部件看起来是同一套东西。

### 4.4 卷胶片（最重要的手感）

- **操作**：鼠标拖动、滚轮（横向或纵向）、← → 方向键，三种都能卷。
- **物理感**：
  - 拖动时胶片跟手；松手后按速度继续滑一段，逐渐减速。
  - 慢下来后吸附到最近的一帧，带一点点回弹，像"咔嗒"一下卡住。
  - 方向键一次走一帧。
  - 胶片两端拖过头时有阻尼，会弹回来。
- **联动**：
  - 每经过一帧，响一下棘轮般的"嗒"（开声音时）。
  - 两个卷片盘随胶片转动；左盘上的胶片越卷越少，右盘越卷越厚；右盘的摇把跟着转。
  - 当前帧被照亮、微微抬起，其他帧变暗；读片口的铜框停稳时发光。
  - 阅读屏幕的空闲画面换成当前帧的标题。
  - 页面顶部中间显示 `02 / 04 · PROJECTS` 这样的计数。
- **起始位置**：About 帧。

### 4.5 载入与返回

**载入**的触发方式：按 Enter、点中间那一帧、点旋钮、点阅读屏幕。点旁边的帧则是把它卷到中间。

载入动画（总共约 1.5 秒，参数可调）：
1. 旋钮"咔"地从 VIEW 转到 LOAD（转 90°），伴随机械声。
2. 屏幕从机器上往前滑出，同时镜头往前推，屏幕最终占画面宽度的 **75%**（这个比例要做成一个可调的设置，网站主人以后看效果再调）。
3. 屏幕以外的部分**压暗并微微虚化**，视线自然落在屏幕上，但机器仍然看得到。
4. 屏幕像老机器开机一样闪几下，然后内容出现。

**返回**的方式（三种都要有）：
- 按 Esc。
- 屏幕下方居中一个**小按钮**：`◀ BACK [ESC]`。样式跟 Skills 的技能方框是一家人（琥珀色发光描边、等宽字体），但做出区别：深色底、方一点的圆角，`ESC` 做成一个浅色小键帽。进入阅读时淡入并轻微脉动两次，提醒访客它在那里。**不要做得太大**（试验版里的大药丸按钮被否决了）。
- 点屏幕外面那圈变暗的机器。

返回动画是载入的倒放：屏幕缩回、镜头拉远、旋钮转回 VIEW，胶片仍停在原来那一帧。

### 4.6 屏幕里的内容

- 内容是**真正的网页元素**（HTML/CSS），精确贴在 3D 屏幕的位置上，不是画成图片贴上去。这样文字清晰、可以选中复制，按钮和链接正常可点。
- 屏幕风格：米黄色纸面，淡淡的扫描线和四周暗角，深棕色文字。
- 内容超过一屏时，在屏幕内部上下滚动，屏幕本身不动。
- 屏幕里的排版跟着屏幕大小等比缩放。

### 4.7 四个栏目

胶片顺序：**About → Projects → Skills → Certificates**。

**About（一进来停在这一帧）**
- 左边：名字、职位、一两段简介、联系方式（邮箱、GitHub、LinkedIn 等，做成档案卡上的几行；链接直接跳转，邮箱可以一键复制）。
- 右边：一张别着回形针、微微歪着的档案卡，上面有照片、教育背景、兴趣方向。

**Projects**
- 列表：一排小胶片帧，每帧一个项目，有编号（P-01、P-02…）、缩略图、项目名。可以左右翻。
- 详情：点开一个项目，显示 `P-03 / Poké-like RPG` 式的标题、一张大图、简介（Overview）、技术栈（Tech Stack，用和 Skills 一样的发光小方框，点了也能弹注释）、可选的 GitHub 链接和在线演示链接（有才显示）。左下角「← All Projects」回到列表。
- 占位：P-01 本地化工具、P-02 AWS 学习、P-03 宝可梦式 RPG。

**Skills**
- 技能按类别分组排列（比如 LANGUAGES / ENGINES / CLOUD / TOOLS），每个技能是一个琥珀色发光描边的小方框（参考游戏 TR-49 里正文中被框起来的编号）。
- 点一个方框，旁边弹出一张米黄色注释卡：技能名、熟练度（例如 ■■■■□）、用了多久、在哪个项目里用过。点别处关闭。

**Certificates**
- 成就徽章墙：每张证书是一枚圆形黄铜徽章，中间是方向图标，下面是证书名。
- 已获得的：发亮、有暖色光晕和一道扫过的高光，鼠标移上去会微微转动。
- 准备中的：灰色、无光，像还没解锁的游戏成就。
- 顶部计数："3 EARNED · 2 IN PROGRESS"。
- 点击徽章弹出卡片：全名、颁发机构、日期、证书编号、"查看证书"链接（准备中的显示"准备中"和预计时间）。

栏目固定为这四个，每个都有自己的专属版面；不需要为"以后加新栏目"做通用版面。

### 4.8 内容数据

- 所有内容（栏目、简介、联系方式、项目、技能、证书）放在数据文件里，3D 版和 2D 版共用。
- 每段文字都有中、英、日三个版本。某个语言缺了某一条，就自动显示英文，不能出现空白。
- 项目图片、照片等放在固定的资源文件夹，数据里写路径。
- 先填占位内容：英文占位，中文和日文先放同样的占位文字。

### 4.9 多语言

- 中、英、日三种。界面文字用一张小的键值翻译表（例如 `nav.about` → 三种语言）。
- 默认语言：按访客浏览器的语言自动选，选不到就用英文；记住访客上次的选择。
- 切换按钮要做成**有风格的**：3D 版里是机器上一个黄铜三档旋钮（`EN · 中 · 日`），拧一下"咔"地跳到下一档，屏幕上的文字闪一下换成新语言。2D 版是同样风格的小旋钮或拨片。
- 字体：英文用衬线体（试验版用的 Cormorant Garamond），数字和标签用等宽字体（IBM Plex Mono），中文和日文各配一款衬线字体（如思源宋体系列），三种放在一起要协调。

### 4.10 2D 简洁版

- **谁会进入**：手机、平板竖屏、不支持 WebGL 的浏览器，自动进入。桌面端右上角有一个「简洁版 / Simple View」按钮可以切过去，2D 版里也有按钮切回 3D。记住访客的选择。
- **样子**：参考[设计图](assets/2026-11-01-moodboard.webp)下半部分的四张小图。深色底，细的暖棕描边面板；顶部左边是 `Optical Archive` 和名字，右边是栏目导航（当前栏目下面有一条下划线）；面板内左侧是 `01 / 04` 编号、大标题和一段说明，右侧是内容（项目用一条带齿孔的胶片框横排展示，About 用歪着的回形针档案卡）；内容下方有翻页圆点。屏幕里的米黄纸面风格（4.6）在 2D 版里用作内容卡片。字体、配色、技能方框、徽章都和 3D 版一致，一看就是同一个网站。
- **操作**：栏目之间可以左右滑动切换，像翻胶片；Projects 里的项目卡片也可以横向滑。
- **内容**：和 3D 版同一份数据。

### 4.11 声音

- 默认开启声音（沉浸感）；右上角有声音开关，访客关掉后会记住。浏览器要等访客第一次点击、轻触或按键后才允许出声，在那之前的声音会被跳过。
- 声音：胶片每过一帧的"嗒"、旋钮的"咔"和机械声、屏幕开机声。试验版是用代码合成的，比较粗糙，正式版可以换成 CC0 音效文件。

### 4.12 视觉风格

- **色调**：近黑的暖棕背景（约 `#0b0806`），暖琥珀色强调（约 `#ffb35c`），黄铜、旧铁，米黄纸面（约 `#efe3c6`）配深棕文字。
- **灯光**：一盏暖色台灯作为主光，加上微弱的环境光和背后的轮廓光。
- **后期效果**：泛光（灯泡、发光边缘）、胶片颗粒、暗角、轻微的偏暖调色、极轻微的光线闪烁。
- **质感**：金属要有磨损和粗糙度变化，不能像塑料或镜面。

## 5. 留给开发者决定的

- 代码结构、模块划分、构建工具的具体配置（倾向 Vite + 原生 JS/TS，不用 React 这类框架，以保持轻量）。
- 数据文件的具体格式和字段名。
- 3D 模型的压缩方式（Draco/meshopt、KTX2 等）。目标：首次加载的资源总量尽量压到试验版（约 13 MB 未压缩）的一半以下。
- 屏幕外壳：目前用老式电视机模型，下方格栅能看出是电视。可以保留，也可以换成更像阅读器遮光罩的造型（代码做或找其他 CC0 模型），只要不破坏"一台机器"的整体感。
- 卷动、载入动画的具体参数（试验版的值可以作为起点）。
- 性能降级策略（比如低端设备关阴影、降分辨率）。
- 是否尊重系统的"减少动态效果"设置，以及怎么减。
- 页面的 SEO 基本信息（标题、描述、分享卡片图）。

## 6. 试验版留下的参考

`spike/` 是用完即弃的试验代码，不直接作为正式代码的基础，但这些东西已经验证过，可以参考：

- 镜头和布局：镜头位置约 `(0, 2.55, 6.6)` 看向 `(0, 1.45, 0)`，视角 34°。胶片中心约 `(0, 0.55, 0.95)`，卷片盘在 x = ±3.05。
- 屏幕推近 75% 的计算方式：按屏幕边框宽度和相机视角反推相机距离。
- 屏幕外压暗加虚化：在后期处理里，按屏幕在画面上的位置做遮罩。
- 模型统一调色：在材质着色器里先把原贴图去色，再混入统一的色调。
- HTML 内容贴合屏幕：每帧把屏幕四角投影到画面上，算出位置和大小。
- 用到的模型都在 `spike/models/`，授权为 CC0（来源 polyhaven.com）。

10. 点屏幕外面也能退出阅读。

## 8. 2026-11-02 修订（以本节为准）

网站主人看过上线前的版本后，经过几轮讨论定下的改动。

### 8.1 机器结构：悬挂式
- **只留屏幕**：去掉屏幕下方的机箱；屏幕只有黄铜边框、玻璃和背板，位于画面正中。
- **机械臂立柱**：屏幕后方台面上有一根两节的立柱，顶上一根向前伸的横梁（导轨）。屏幕挂在可沿导轨滑动的吊架上；载入时吊架带着屏幕向前推。
- **横杆与转轮**：前方一根横杆，两端各垂下一根细黄铜杆吊住一个转轮。转轮左高右低，不和屏幕相连。
- **转轮**：全部代码建模，重点在材质——做旧黄铜侧板（镂空、车床纹、铜绿）、有光泽的胶片卷（细年轮纹，厚度随进度变化）、钢轴和螺丝。
- **胶片**：胶片帧宽度 = 间距 = 1.0；两端各有一个细长的导轮闸，位置正好在 ±2.5 帧，胶片停稳时画面里是 5 张完整的胶片，不出现半张。胶片进入导轮闸后，从闸顶的小导轮出来，变成一条等宽、不扭转的细胶片，竖直卷进转轮。
- **吊灯**：不用台灯模型，改为从前横杆垂下的吊灯，灯罩照向读片口；亮度由 `LAMP_INTENSITY` 控制。
- **旋钮横杆**（2026-11-03 更新）：屏幕下方一根细黄铜横杆，两端由立柱撑在台面上，中间吊一块 OR-3 小铜牌。两个旋钮挂在横杆上：鸡头形哑光铜指针，转轴在刻度盘下部；刻度盘上半部是一道刻度弧，档位文字刻在弧外——左为 `EN · 中 · 日`（中 居中），右只刻 `VIEW`（居中），LOAD 档只有一道刻痕。所有字同样大小、常规粗细，由指针表示当前档位；鼠标移上去时刻度变亮、旋钮略抬起，不发光。
- 场景里不再使用任何外部 3D 模型。

### 8.2 交互
- **载入**：无论从哪里触发，先看到 VIEW 旋钮转到 LOAD（0.6 秒），然后屏幕推近。
- **返回**：BACK 是印在纸面右下角的一个小标签（衬线小型大写字母、细棕色边框、浅色键帽 `ESC`），不再放在屏幕外；Esc 和点击屏幕外仍可返回。
- **时钟**：屏幕空闲画面右上角显示访客本地时间和日期；去掉了画面顶部的 `01 / 04 · ABOUT` 计数。

### 8.3 开场后的问候
- 开场动画淡出时，屏幕已经是推近状态，直接显示问候页：时间问候（含访客城市）、运营商、估算网速、提供网页的 CDN 节点、连接好坏和表情。
- 打完字后停留 3 秒，屏幕缩回到 About；按任意键、点 BACK 或点屏幕外可提前返回。问候不会转动 VIEW 旋钮。
- 城市和运营商来自第三方 ipapi.co（访客 IP 会发给它，不保存）；节点来自 GitHub Pages（Fastly）回应头 `x-served-by`；网速用资源下载时间估算。查不到的显示"未知"。
- 只在 3D 版显示。

### 8.4 其他
- **日文字体**：MS Mincho（Windows 自带），其他系统回退到 Noto Serif JP。
- **2D 版**：页面最大宽度 1240px 居中，内容卡片和 3D 屏幕同比例（23:15），内容更长时自动加高；手机上不限制比例。
- **音效**（2026-11-03）：屏幕亮起时是快门/光圈的两段式"咔—嚓"机械声，取代原来的电子嗡声。
